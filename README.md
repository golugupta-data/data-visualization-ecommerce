# Data Visualization – E-commerce Dataset

## 📌 Project Overview

This project was completed as part of my **Data Analytics Internship at Decode Labs**.

The project focuses on transforming e-commerce data into clear and meaningful visualizations using Python.

## 🏢 Organization

**Decode Labs**

**Role:** Data Analytics Intern

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Visualizations Created

### 1. Product Revenue Analysis
A bar chart was used to compare the revenue generated by different products.

### 2. Monthly Revenue Trend
A line chart was used to identify changes in revenue over time.

### 3. Payment Method Analysis
A bar chart was used to compare revenue across different payment methods.

### 4. Order Status Analysis
A bar chart was used to understand the distribution of order statuses.

### 5. Quantity vs Total Price
A scatter plot was used to understand the relationship between quantity and total order price.

### 6. Product Quantity Analysis
A bar chart was used to identify the products with the highest quantity sold.

## 🎯 Project Objective

The objective of this project is to create clean and meaningful visualizations and communicate useful business insights from an e-commerce dataset.

## 🔍 Key Insights

- Identified top revenue-generating products.
- Analyzed monthly revenue trends.
- Compared payment methods based on revenue.
- Analyzed order status distribution.
- Studied the relationship between quantity and total price.
- Identified products with the highest quantity sold.
